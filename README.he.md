# 🐜 נמלה (Nemla) — כלי לסיור ברשת

**גילוי · סריקה · זיהוי · דיווח**

[English](README.md) · [العربية](README.ar.md) · **עברית**

נמלה (בערבית: **نملة**) היא כלי קטן לסיור ברשת, כתוב ב-Python וללא תלויות חיצוניות. תנו לה כתובת IP, שם אתר, טווח או רשת שלמה, והיא תמצא מכשירים פעילים, תסרוק פורטי TCP, תזהה מה רץ עליהם (מוצרים, גרסאות, תעודות TLS), תנחש את מערכת ההפעלה, תגיד במילים פשוטות מה נראה מסוכן, ותכתוב **דוח HTML** נקי (וגם JSON ו-CSV לסקריפטים). הממשק והדוח זמינים **באנגלית, בערבית ובעברית**.

## למה נמלה?

[nmap](https://nmap.org) חזק בהרבה, ומומלץ להשתמש בו לעבודה רצינית. נמלה נועדה לרגעים שבהם רוצים משהו קטן יותר:

- **בלי התקנה**: ספרייה סטנדרטית של Python בלבד. הסורק הוא קובץ אחד (`nemla.py`), והממשק התלת־ממדי ומצב השמירה נמצאים בתיקייה אופציונלית `nemla_ui/` לידו. Scapy אופציונלית.
- **דוח שאפשר למסור למישהו**: דף HTML כהה וקריא, בלי המרות XML.
- **ערבית ועברית**: `--lang ar` או `--lang he` הופכים את כל שורת הפקודה, הדוח והממשק לערבית או לעברית מימין לשמאל.
- **קוד קריא**: Python רגיל בלי מסגרות. התחילו מ-`main()` ומ-`run_scan()` ב-`nemla.py`; חלק גדול מהקובץ הוא טבלאות תרגום. זה מתאים ללימוד איך סורקים עובדים.

## מה נמלה מספרת לכם

מלבד פורטים פתוחים, נמלה מזהה מה רץ ואומרת מה זה אומר:

- **מוצרים וגרסאות** מתוך באנרים ובדיקות קלות (OpenSSH, nginx, Apache, vsftpd, Postfix, MySQL, PostgreSQL, Redis ועוד), וגם כותרות של דפי אינטרנט.
- **פרטי TLS**: גרסת הפרוטוקול, נושא ומנפיק התעודה, תאריך התפוגה, והאם התעודה חתומה עצמית.
- **מי יצר אותו**: כשגילוי ARP מחזיר כתובת MAC, נמלה מציינת את הפלטפורמה שמאחורי קידומות מוכרות (VMware, VirtualBox, Hyper-V, Xen, QEMU/KVM, Docker, Raspberry Pi). זו רשימה קטנה שנבחרה ידנית ולא כל מרשם IEEE, ולכן ברוב הכתובות לא יוצג שם.
- **ממצאים** במילים פשוטות, כל אחד בדירוג גבוה, בינוני, נמוך או מידע: שירותים ללא הצפנה כמו Telnet ו-FTP, מסדי נתונים ופורטי גישה מרחוק שנגישים, Redis, Memcached או Elasticsearch שעונים בלי סיסמה, תעודות שפג תוקפן או עומד לפוג, גרסאות TLS מיושנות, אתרים בלי HTTPS. חשיפה בכתובת IP ציבורית מדורגת גבוה יותר מאשר ברשת פרטית.
- הממצאים הם תצפיות בלבד. נמלה לעולם לא מתחברת, לא מנחשת סיסמאות ולא מנצלת שום פרצה.

לשימוש בסקריפטים וב-CI: הפקודה הבאה יוצאת עם קוד 3 כשיש ממצא ברמה הזו ומעלה.

</div>

```bash
python3 nemla.py -t 10.0.0.0/24 --fail-on high
```

## מה השתנה מאז הפעם הקודמת

נמלה זוכרת את הסריקות שלכם (60 האחרונות, בתיקיית הנתונים של נמלה) ומשווה כל סריקה חדשה לקודמת של אותו יעד: מכשירים שהופיעו או נעלמו, פורטים שנפתחו או נסגרו, שירותים שהמוצר או הגרסה שלהם השתנו, ניחוש מערכת אחר, וממצאים שהופיעו או טופלו. בממשק התלת־ממדי זה מוצג ככרטיס מעל רשימת המכשירים, מכשירים חדשים פועמים בכחול ומכשירים שנעלמו נשארים כקו מקווקו.

בשורת הפקודה:

</div>

```bash
python3 nemla.py -t 192.168.1.0/24 --json today.json
```

```bash
python3 nemla.py --diff yesterday.json today.json
```

<div dir="rtl">

`--diff` מדפיס את השינויים, ועם `--fail-on-change` הוא יוצא עם קוד 3 אם הופיע משהו (מכשיר, פורט פתוח או ממצא), וזה מתאים לבדיקות מתוזמנות.

כדי לעקוב אחרי רשת, תנו לנמלה לסרוק שוב ושוב ולדווח על כל שינוי (עוצרים עם Ctrl+C):

</div>

```bash
python3 nemla.py -t 192.168.1.0/24 --watch 15m --watch-log changes.jsonl
```

<div dir="rtl">

את המרווח אפשר לכתוב `90s`, `15m` או `2h` (לפחות 10 שניות). כל סבב נשמר, ולכן ההרצה הבאה ממשיכה מהאחרון.

## מצב שמירה (הגנתי)

נמלה יכולה גם לשמור על רשת במקום לסרוק אותה. מצב שמירה מחפש שלושה סימנים לכך שמשהו חשוד קורה בתוך הרשת שלכם:

- **פורטי פיתיון**: נמלה פותחת כמה פורטים שאין לשום מכשיר או אדם לגיטימי סיבה לגעת בהם (2222, 2323, 5901, 8888 ו-3307 כברירת מחדל). כל מי שמתחבר לאחד מהם בודק את הרשת שלכם, ונמלה רושמת מי זה היה ומה שלח. כך יש מעט מאוד אזעקות שווא.
- **מכשירים לא מוכרים**: הבדיקה הראשונה לומדת את המכשירים שלכם לפי כתובת החומרה (MAC). מאז, מכשיר שלא היה שם קודם מקפיץ התראה. כשהכתובת שייכת לפלטפורמה מוכרת ההתראה מציינת אותה (למשל Raspberry Pi או מכונה וירטואלית), והיא אומרת כשהכתובת "מוגדרת מקומית", כפי שעושים מכונות וירטואליות, קונטיינרים וטלפונים עם כתובת Wi-Fi פרטית.
- **שינויי ARP**: אם כתובת פתאום עונה ממכשיר אחר, ובעיקר שער הרשת שלכם, זה העקבות הקלאסיים של התחזות ARP (אדם באמצע).

מצב שמירה רק מנטר ומתריע. הוא לא תוקף בחזרה, לא סורק מכשירים אחרים בעצמו ולא משנה את חומת האש: עבור מכשיר שרוצים לחסום הוא מציג את הפקודה המדויקת ומשאיר לכם להריץ אותה.

</div>

```bash
python3 nemla.py --guard
```

<div dir="rtl">

או הפעילו **שמירה** בממשק התלת־ממדי: המסך מהבהב, המקור נדלק באדום במפה, וכל התראה אומרת מה לעשות אחר כך. הממשק שומר רק כל עוד הוא פתוח. להגנה רציפה הריצו `nemla --guard` (למשל על Raspberry Pi), ואפשר להוסיף `--guard-log alerts.jsonl` כדי לשמור את ההתראות גם כשורות JSON.

הערות: פורטי פיתיון מעל 1024 לא דורשים הרשאות מיוחדות, ושום דבר במצב שמירה לא צריך root. חיבורים מהמחשב שמריץ את מצב שמירה מתעלמים, וטלפונים שמשנים את כתובת ה-Wi-Fi שלהם באקראי עלולים להיראות כמכשירים חדשים.

## הממשק התלת־ממדי

הריצו את נמלה בלי פרמטרים והיא תפתח חלון משלה: מפה תלת־ממדית של הרשת, טופס סריקה, רשימת מכשירים חיה ולוח פרטים לכל מכשיר. זה אותו סורק כמו בשורת הפקודה, רק נוח יותר לעבודה.

![הממשק התלת־ממדי של נמלה עם מושבת ההדגמה](docs/ui-3d.png)

> צילום המסך הוא ממושבת ההדגמה המובנית (מכשירים מומצאים). מכשירים חדשים פועמים בכחול, העיגול המקווקו הוא מכשיר שנעלם, והכרטיס מציג מה השתנה מאז הסריקה הקודמת.

</div>

```bash
python3 nemla.py            # פותח את הממשק התלת־ממדי
```

<div dir="rtl">

- **מבט המושבה**: המחשב שלכם הוא הקן באמצע, כל מכשיר שנמצא מרחף סביבו, וכל פורט פתוח מקיף את המכשיר שלו בצבע לפי סוג השירות (אינטרנט, גישה מרחוק, מסד נתונים, דואר, קבצים). גוררים לסיבוב, גוללים לזום, לוחצים על מכשיר כדי לבדוק אותו.
- **חי**: מכשירים ופורטים מופיעים בזמן הסריקה. עצירה שומרת את התוצאות החלקיות.
- **סיכון במבט אחד**: מכשירים עם ממצאים בדרגה גבוהה או בינונית פועמים בוורוד או בזהב במפה, ולוח הפרטים מפרט כל ממצא עם חומרתו.
- **ייצוא**: דוח HTML, JSON או CSV מכפתור הייצוא.
- **אנגלית, ערבית ועברית** כולל מימין לשמאל, עם תפריט שפות.
- **ניסיון בלי סריקה**: "צפו במושבה לדוגמה" מנגן רשת מומצאת.
- **ספרייה סטנדרטית בלבד**: הממשק הוא שרת אינטרנט מקומי קטן ודף אחד. אין מה להתקין והוא עובד בלי אינטרנט.

### הוספת נמלה לתפריט היישומים של לינוקס

</div>

```bash
python3 nemla.py --install-launcher     # פריט תפריט, אייקון ופקודת nemla, הכול תחת ~/.local
python3 nemla.py --uninstall-launcher   # מסיר אותם שוב
```

<div dir="rtl">

אחר כך פתחו את **נמלה** מתפריט היישומים (או הקלידו `nemla`). בדפדפן ממשפחת Chromium (Chrome, Chromium, Brave, Edge) היא נפתחת כחלון משלה בלי מסגרת הדפדפן, ובכל מקרה אחר בדפדפן ברירת המחדל. סגירת החלון עוצרת את נמלה.

גילוי ARP דורש root, ודפדפנים מסרבים לעלות כ-root, ולכן במקרה הזה הריצו `sudo python3 nemla.py --no-browser` ופתחו את הכתובת שמודפסת בדפדפן שלכם. דרך SSH, העבירו את הפורט (`ssh -L PORT:127.0.0.1:PORT host`) ופתחו את הכתובת אצלכם.

### איך זה נשאר בטוח

הממשק מאזין רק על `127.0.0.1`. כל בקשה דורשת אסימון אקראי שקיים רק בקישור שנמלה פותחת, וכותרות `Host` ו-`Origin` נבדקות, כך שאתרים אחרים ומחשבים אחרים לא יכולים להתחיל סריקות. טקסט שנסרק (באנרים, מחרוזות מערכת הפעלה) מוצג כטקסט רגיל ולעולם לא כ-HTML, והדף רץ תחת מדיניות אבטחת תוכן מחמירה. הסריקה הראשונה מבקשת שתאשרו שהרשת בבעלותכם או שמותר לכם לבדוק אותה.

## התחלה מהירה

</div>

```bash
# רשת שלמה, פורטים נפוצים
sudo python3 nemla.py -t 192.168.1.0/24

# מכשיר אחד, פורטים 1-1000
python3 nemla.py -t 192.168.1.10 -p 1-1000

# טווחים: צורה קצרה או מלאה
python3 nemla.py -t 192.168.1.1-50
python3 nemla.py -t 192.168.1.1-192.168.2.20

# פורטים מסוימים + פלט JSON ו-CSV
python3 nemla.py -t 192.168.1.10 -p 22,80,443 --json scan.json --csv scan.csv

# ממשק ודוח בעברית
python3 nemla.py -t 192.168.1.10 --lang he

# היעד חוסם ping? מדלגים על הגילוי (כמו nmap -Pn)
python3 nemla.py -t 192.168.1.10 --no-ping
```

<div dir="rtl">

`sudo` נדרש רק לגילוי ARP ולבדיקת TTL בעזרת ICMP גולמי דרך Scapy. בלעדיו נמלה חוזרת ל-`ping` של המערכת ולחיבורי TCP רגילים.

## אפשרויות

| אפשרות | תיאור |
| --- | --- |
| `-t`, `--target` | IP, שם מארח, CIDR (`10.0.0.0/24`), טווח קצר (`10.0.0.1-50`) או טווח מלא (`10.0.0.1-10.0.0.50`) |
| `-p`, `--ports` | `22`, `22,80,443`, `1-1000` או שילוב |
| `--top-ports` | סורק גם את רשימת הפורטים הנפוצים (זו ברירת המחדל כש-`-p` לא צוין) |
| `-o`, `--output` | נתיב דוח ה-HTML (ברירת מחדל `nemla_report.html`) |
| `--json FILE` | כותב את התוצאות גם כ-JSON |
| `--csv FILE` | כותב את התוצאות גם כ-CSV |
| `--no-ping` | מדלג על גילוי מכשירים ומתייחס לכל יעד כפעיל |
| `--no-os` | מדלג על זיהוי מערכת ההפעלה |
| `--no-banner` | מדלג על קריאת באנרים וזיהוי שירותים (גרסאות, TLS, כותרות אתרים) |
| `--fail-on LEVEL` | קוד יציאה 3 אם יש ממצא ברמה `low`, `medium` או `high` ומעלה |
| `--watch INTERVAL` | סורק שוב כל `90s`, `15m` או `2h` ומדווח על שינויים; עוצרים עם Ctrl+C |
| `--watch-log FILE` | מוסיף כל שינוי ש-`--watch` מצא לקובץ JSON lines |
| `--diff OLD.json NEW.json` | משווה שתי סריקות שנשמרו עם `--json` ומדפיס מה השתנה |
| `--fail-on-change` | עם `--diff`: קוד יציאה 3 אם הופיע מכשיר, פורט פתוח או ממצא |
| `--guard` | מנטר את הרשת לפעילות חשודה ומדפיס התראות עד Ctrl+C |
| `--guard-ports LIST` | פורטי פיתיון לפתיחה (ברירת מחדל `2222,2323,5901,8888,3307`) |
| `--guard-interval SECONDS` | שניות בין בדיקות מכשירים (ברירת מחדל 60, `0` פירושו פורטי פיתיון בלבד) |
| `--guard-log FILE` | מוסיף התראות גם לקובץ JSON lines |
| `--threads N` | מספר תהליכונים (ברירת מחדל 150) |
| `--timeout S` | זמן קצוב לחיבור TCP בשניות (ברירת מחדל 0.7) |
| `--max-hosts N` | מסרב ליעדים גדולים מ-N כתובות (ברירת מחדל 1024) |
| `--lang en\|ar\|he` | שפת שורת הפקודה, הדוח והממשק (ברירת מחדל `en`) |
| `--version` | מדפיס את הגרסה |
| `--ui` | פותח את הממשק התלת־ממדי (גם מה שקורה בלי פרמטרים) |
| `--ui-port PORT` | פורט לשרת הממשק המקומי (ברירת מחדל: כל פורט פנוי) |
| `--no-browser` | מפעיל את שרת הממשק בלי לפתוח חלון |
| `--keep-alive` | משאיר את השרת רץ אחרי שהחלון שלו נסגר |
| `--install-launcher` / `--uninstall-launcher` | לינוקס: הוספה או הסרה של פריט תפריט היישומים |

## איך זה עובד

1. **גילוי**: ARP ברשתות מקומיות (דורש Scapy ו-root). אם ARP לא מוצא כלום, או שהיעד לא מקומי, נמלה חוזרת ל-ICMP (`ping` של המערכת) ולבדיקות TCP. חיבור TCP ש*נדחה* עדיין מוכיח שהמכשיר חי.
2. **סריקת פורטים**: סריקת חיבור TCP במקביל (`ThreadPoolExecutor`). שמות השירותים באים מטבלה מובנית עם גיבוי למסד השירותים של המערכת.
3. **קריאת באנרים וזיהוי**: נמלה מקשיבה קודם (SSH, FTP ו-SMTP פותחים בברכה). אם הפורט שותק, היא שולחת `HEAD` תמים של HTTP, אבל רק בפורטי HTTP ובפורטים בלי שירות לא־HTTP מוכר. בפורטים פתוחים היא מריצה בדיקות זיהוי רגילות: `GET` לכותרת הדף, לחיצת יד TLS לתעודה, `PING` של Redis, `version` של Memcached, בקשת SSL של PostgreSQL. שום דבר לא מתחבר ושום דבר לא משנה מצב. `--no-banner` מדלג על כל זה.
4. **ניחוש מערכת הפעלה**: היוריסטיקה: TTL (‏≤64 לינוקס/יוניקס/macOS, ‏≤128 Windows, אחרת ציוד רשת) בשילוב פורטים פתוחים (RDP/SMB, SSH). התייחסו לזה כאומדן.
5. **דוח**: HTML (כל הנתונים הנסרקים עוברים escape, כי הבאנרים באים ממכשירים לא אמינים), ובנוסף JSON/CSV אופציונליים.

## מגבלות

- IPv4 בלבד, סריקת חיבור TCP בלבד (בלי SYN או UDP).
- הממצאים מתארים חשיפה ולא פגיעויות: נמלה לא משווה גרסאות למסד CVE.
- זיהוי מערכת ההפעלה הוא היוריסטיקת TTL ופורטים, לא טביעת אצבע אמיתית.
- חומות אש שמפילות חבילות יגרמו למכשירים להיראות כבויים. נסו `--no-ping` ו-`--timeout` גדול יותר.

**סרקו רק מערכות ורשתות שבבעלותכם או שיש לכם אישור מפורש וכתוב לבדוק.** סריקה ללא הרשאה עלולה להפר חוקים, תנאי ספקים ומדיניות ארגונית. נמלה היא כלי סיור: היא מגלה ומדווחת, היא לא מנצלת דבר, וזה מכוון. המחבר אינו אחראי לשימוש לרעה.
