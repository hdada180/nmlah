# 🐜 نملة (Nemla) — أداة استطلاع الشبكات

**اكتشاف · فحص · تخمين · تقرير**

[English](README.md) · **العربية** · [עברית](README.he.md)

نملة أداة صغيرة مكتوبة بلغة Python، بدون أي مكتبات إضافية مطلوبة. أعطها عنوان IP أو اسم موقع أو نطاق أو شبكة كاملة، فتكتشف الأجهزة الشغّالة، وتفحص منافذ TCP، وتقرأ لافتات الخدمات (Banners)، وتخمّن نظام التشغيل، وتكتب لك **تقرير HTML** مرتباً، مع خرج JSON وCSV إذا بدك تستخدمه في سكربتات. الواجهة والتقرير يشتغلوا **بالعربي والإنجليزي والعبري**.

## ليش نملة؟

أداة [nmap](https://nmap.org) أقوى بكثير وهي الخيار للشغل الجدي. نملة للحالات اللي بدك فيها شي أخف:

- **بدون تثبيت**: مكتبات بايثون القياسية فقط. الفاحص ملف واحد (`nemla.py`)، والواجهة ثلاثية الأبعاد ووضع الحراسة بمجلد `nemla_ui/` اختياري جنبه. مكتبة Scapy اختيارية.
- **تقرير جاهز للتسليم**: صفحة HTML داكنة وواضحة.
- **عربي وعبري**: خيار `--lang ar` أو `--lang he` بيحوّل الواجهة والتقرير كلهم للعربي أو العبري (من اليمين لليسار).
- **كود مقروء**: بايثون عادي بدون أطر عمل. ابدأ من `main()` و`run_scan()` بملف `nemla.py`، وجزء كبير من الملف جداول ترجمة. وهذا بيخليه ممتاز لتتعلم كيف بتشتغل أدوات الفحص.

## شو بتقلك نملة

غير المنافذ المفتوحة، نملة بتحدد شو الشغّال وبتشرح شو معناه:

- **المنتجات ونسخها** من اللافتات وفحوصات خفيفة (OpenSSH وnginx وApache وvsftpd وPostfix وMySQL وPostgreSQL وRedis وغيرها)، مع عناوين صفحات الويب.
- **تفاصيل TLS:** نسخة البروتوكول، وصاحب الشهادة وجهة إصدارها، وتاريخ انتهائها، وإذا كانت موقّعة ذاتياً.
- **ملاحظات** بكلام بسيط ولكل وحدة مستوى (عالية، متوسطة، منخفضة، معلومة): خدمات بدون تشفير مثل Telnet وFTP، وقواعد بيانات ومنافذ وصول عن بُعد ظاهرة، وRedis أو Memcached أو Elasticsearch بيردوا بدون كلمة سر، وشهادات منتهية أو قريبة تنتهي، ونسخ TLS قديمة، ومواقع بدون HTTPS. الظهور على عنوان عام (إنترنت) بينحسب أخطر من الظهور على شبكة خاصة.
- الملاحظات وصف لما بيتشاف بس. نملة ما بتسجّل دخول ولا بتخمّن كلمات سر ولا بتستغل أي ثغرة.

للاستخدام بالسكربتات وأنظمة CI، الأمر التالي بيرجع رمز خروج 3 إذا في ملاحظة بهالمستوى أو أعلى:

</div>

```bash
python3 nemla.py -t 10.0.0.0/24 --fail-on high
```

## شو تغيّر من آخر مرة

نملة بتتذكّر فحوصاتك (آخر 60 بمجلد بيانات نملة) وبتقارن كل فحص جديد مع الفحص السابق لنفس الهدف: أجهزة ظهرت أو اختفت، ومنافذ انفتحت أو انسكّرت، وخدمات تغيّر منتجها أو نسختها، وتخمين نظام مختلف، وملاحظات ظهرت أو انعالجت. بالواجهة ثلاثية الأبعاد بيبين كبطاقة فوق قائمة الأجهزة، والأجهزة الجديدة بتنبض بالأزرق والأجهزة المختفية بتضل كخط متقطّع.

بسطر الأوامر:

</div>

```bash
python3 nemla.py -t 192.168.1.0/24 --json today.json
```

```bash
python3 nemla.py --diff yesterday.json today.json
```

<div dir="rtl">

`--diff` بيطبع التغييرات، ومع `--fail-on-change` بيرجع رمز خروج 3 إذا ظهر شي (جهاز أو منفذ مفتوح أو ملاحظة)، وهاد مناسب للفحوصات المجدولة.

لتراقب شبكة، خلّي نملة تفحص مرة بعد مرة وتبلّغ عن كل تغيير (وقّف بـ Ctrl+C):

</div>

```bash
python3 nemla.py -t 192.168.1.0/24 --watch 15m --watch-log changes.jsonl
```

<div dir="rtl">

الفاصل الزمني بتكتبه `90s` أو `15m` أو `2h` (10 ثوانٍ على الأقل). كل جولة بتنحفظ، فالتشغيل الجاي بيكمل من آخر وحدة.

## وضع الحراسة (دفاعي)

نملة بتقدر كمان تراقب الشبكة بدل ما تفحصها. وضع الحراسة بيدوّر على ثلاث علامات إنو في شي مشبوه جوا شبكتك:

- **منافذ الطُّعم:** نملة بتفتح كم منفذ ما في أي جهاز أو شخص سليم إلو سبب يلمسهم (2222 و2323 و5901 و8888 و3307 افتراضياً). أي شي بيتصل فيهم عم يجس نبض شبكتك، ونملة بتسجّل مين هو وشو بعت. إنذارات كاذبة قليلة جداً.
- **أجهزة مجهولة:** أول فحص بيتعلّم أجهزتك من عنوان العتاد (MAC). بعدها أي جهاز ما كان موجود بيطلّع تنبيه. إذا العنوان لمنصة معروفة التنبيه بيسمّيها (مثلاً Raspberry Pi أو جهاز افتراضي)، وبيقلك إذا العنوان «معيَّن محلياً»، وهاد اللي بتستخدمه الأجهزة الافتراضية والحاويات والجوالات اللي عندها عنوان Wi-Fi خاص.
- **تغيّر ARP:** إذا عنوان فجأة صار يردّ من جهاز ثاني، وبالأخص البوابة، هاي العلامة الكلاسيكية لانتحال ARP (رجل في المنتصف).

الحراسة بتراقب وبتنبّه بس. ما بترد هجوم، وما بتفحص أجهزة ثانية لحالها، وما بتغيّر الجدار الناري: إذا بدك تحظر جهاز بتعرض لك الأمر بالضبط وإنت بتشغّله.

</div>

```bash
python3 nemla.py --guard
```

<div dir="rtl">

أو شغّل **الحراسة** من الواجهة ثلاثية الأبعاد: الشاشة بتومّض، والمصدر بيتوهّج أحمر على الخريطة، وكل تنبيه بيقلك شو تعمل بعدين. الواجهة بتحرس بس وهي مفتوحة. لحماية دائمة شغّل `nemla --guard` (مثلاً على Raspberry Pi)، ومع `--guard-log alerts.jsonl` بتنحفظ التنبيهات كمان بملف JSON lines.

ملاحظات: منافذ الطُّعم فوق 1024 ما بتحتاج صلاحيات خاصة، وما في شي بالحراسة بده root. الاتصالات من الجهاز اللي شغّال عليه الحراسة بتنتجاهل، والجوالات اللي بتغيّر عنوان الواي فاي عشوائياً ممكن تبين كأجهزة جديدة.

## الواجهة ثلاثية الأبعاد

شغّل نملة بدون أي خيارات وبتفتح نافذتها الخاصة: خريطة 3D لشبكتك، ونموذج فحص، وقائمة أجهزة مباشرة، ولوحة تفاصيل لكل جهاز. هو نفس الفاحص تبع سطر الأوامر، بس أسهل بالشغل.

![واجهة نملة ثلاثية الأبعاد بالمستعمرة التجريبية](docs/ui-3d.png)

> اللقطة من المستعمرة التجريبية المدمجة (أجهزة مختلقة). الأجهزة الجديدة بتنبض بالأزرق، والدائرة المتقطعة على الشمال جهاز اختفى، والبطاقة بتبيّن شو تغيّر من الفحص السابق.

</div>

```bash
python3 nemla.py            # بتفتح الواجهة ثلاثية الأبعاد
```

<div dir="rtl">

- **منظر المستعمرة:** جهازك هو العش بالنص، وكل جهاز مكتشف بيطفو حواليه، وكل منفذ مفتوح بيدور حول جهازه بلون حسب نوع الخدمة (ويب، وصول عن بُعد، قواعد بيانات، بريد، ملفات). اسحب للتدوير، مرّر للتقريب، اضغط على جهاز لتشوف تفاصيله.
- **مباشر:** الأجهزة والمنافذ بتظهر أثناء الفحص، وزر الإيقاف بيحتفظ بالنتائج الجزئية.
- **تصدير:** تقرير HTML أو JSON أو CSV من زر التصدير.
- **عربي وإنجليزي وعبري** مع دعم كامل من اليمين لليسار وقائمة لغات.
- **جرّبها بدون فحص:** زر «شاهد مستعمرة تجريبية» بيعرض شبكة مختلقة.
- **مكتبات بايثون القياسية فقط:** الواجهة خادم محلي صغير وصفحة واحدة، بدون أي تثبيت وبتشتغل بدون إنترنت.

### إضافة نملة لقائمة تطبيقات لينكس

</div>

```bash
python3 nemla.py --install-launcher     # أيقونة وإدخال بالقائمة وأمر nemla، كلها تحت ~/.local
python3 nemla.py --uninstall-launcher   # لإزالتهم
```

<div dir="rtl">

بعدها افتح **نملة** من قائمة التطبيقات (أو اكتب `nemla`). مع متصفح من عائلة Chromium (Chrome وChromium وBrave وEdge) بتفتح بنافذة لحالها بدون شريط المتصفح، وغير هيك بمتصفحك الافتراضي. سكّر النافذة وبتتوقف نملة.

اكتشاف ARP بده صلاحيات الجذر والمتصفحات بترفض تشتغل كجذر، فبهاي الحالة شغّل `sudo python3 nemla.py --no-browser` وافتح العنوان اللي بيطبعه بمتصفحك. عبر SSH، مرّر المنفذ (`ssh -L PORT:127.0.0.1:PORT host`) وافتح العنوان عندك.

### كيف بتضل آمنة

الواجهة بتسمع على `127.0.0.1` فقط. كل طلب بده رمز عشوائي موجود بس بالرابط اللي بتفتحه نملة، وبيتحقق من ترويستي `Host` و`Origin`، فما بتقدر مواقع ثانية ولا أجهزة ثانية تبدأ فحوصات. النصوص اللي بتجي من الأجهزة المفحوصة (اللافتات ونظام التشغيل) بتنعرض كنص عادي وليس HTML، والصفحة شغّالة تحت سياسة أمان محتوى صارمة. أول فحص بيطلب منك تأكيد إنك بتملك الشبكة أو مسموح لك تختبرها.

## أمثلة

</div>

```bash
# شبكة كاملة بالمنافذ الشائعة
sudo python3 nemla.py -t 192.168.1.0/24 --lang ar

# جهاز واحد، منافذ 1 إلى 1000
python3 nemla.py -t 192.168.1.10 -p 1-1000 --lang ar

# نطاق (بصيغة مختصرة أو كاملة)
python3 nemla.py -t 192.168.1.1-50
python3 nemla.py -t 192.168.1.1-192.168.2.20

# منافذ محددة مع خرج JSON وCSV
python3 nemla.py -t 192.168.1.10 -p 22,80,443 --json scan.json --csv scan.csv

# الهدف بيحجب ping؟ تخطّى الاكتشاف
python3 nemla.py -t 192.168.1.10 --no-ping
```

<div dir="rtl">

الأمر `sudo` مطلوب فقط لاكتشاف ARP وقراءة TTL عبر Scapy. بدونه، بترجع نملة تستخدم أمر `ping` الخاص بالنظام واتصالات TCP العادية.

## الخيارات

| الخيار | الوصف |
| --- | --- |
| `-t`, `--target` | IP أو اسم مضيف أو CIDR أو نطاق |
| `-p`, `--ports` | `22` أو `22,80,443` أو `1-1000` |
| `--top-ports` | إضافة قائمة المنافذ الشائعة (وهي الافتراضي إذا ما حددت `-p`) |
| `-o`, `--output` | مسار تقرير HTML |
| `--json FILE` / `--csv FILE` | خرج إضافي بصيغة JSON أو CSV |
| `--no-ping` | تخطي اكتشاف الأجهزة |
| `--no-os` | تخطي تخمين نظام التشغيل |
| `--no-banner` | تخطي قراءة الـ Banner |
| `--threads N` | عدد الخيوط (الافتراضي 150) |
| `--timeout S` | مهلة الاتصال بالثواني (الافتراضي 0.7) |
| `--max-hosts N` | رفض الأهداف الأكبر من N عنوان (الافتراضي 1024) |
| `--lang en\|ar\|he` | لغة الواجهة والتقرير (إنجليزي، عربي، عبري) |
| `--fail-on LEVEL` | رمز خروج 3 إذا وُجدت ملاحظة بمستوى `low` أو `medium` أو `high` أو أعلى |
| `--watch INTERVAL` | إعادة الفحص كل `90s` أو `15m` أو `2h` والإبلاغ عن التغييرات (وقّف بـ Ctrl+C) |
| `--watch-log FILE` | حفظ كل تغيير يلاقيه `--watch` بملف JSON lines |
| `--diff OLD.json NEW.json` | مقارنة فحصين محفوظين بـ `--json` وطباعة التغييرات |
| `--fail-on-change` | مع `--diff`: رمز خروج 3 إذا ظهر جهاز أو منفذ مفتوح أو ملاحظة |
| `--guard` | مراقبة الشبكة لنشاط مشبوه وطباعة التنبيهات حتى Ctrl+C |
| `--guard-ports LIST` | منافذ الطُّعم (الافتراضي `2222,2323,5901,8888,3307`) |
| `--guard-interval SECONDS` | الثواني بين فحوصات الأجهزة (الافتراضي 60، و`0` = منافذ الطُّعم فقط) |
| `--guard-log FILE` | حفظ التنبيهات كمان بملف JSON lines |
| `--ui` | فتح الواجهة ثلاثية الأبعاد (وهي الافتراضي بدون خيارات) |
| `--ui-port PORT` | منفذ خادم الواجهة المحلي (الافتراضي: أي منفذ فاضي) |
| `--no-browser` | تشغيل خادم الواجهة بدون فتح نافذة |
| `--keep-alive` | إبقاء الخادم شغّال بعد إغلاق نافذته |
| `--install-launcher` / `--uninstall-launcher` | لينكس: إضافة أو إزالة مدخل قائمة التطبيقات |

## القيود

- IPv4 فقط، وفحص TCP connect فقط (بدون SYN أو UDP).
- تخمين نظام التشغيل تقديري (TTL والمنافذ المفتوحة) وليس بصمة حقيقية.
- الجدران النارية اللي بتُسقط الحزم ممكن تخلي الأجهزة تبين مطفية. جرّب `--no-ping` ومهلة أكبر.

## الاستخدام المسؤول

**افحص فقط الأنظمة والشبكات اللي بتملكها أو عندك إذن صريح ومكتوب لفحصها.** الفحص بدون تصريح ممكن يخالف القوانين وشروط مزوّد الخدمة وسياسات المؤسسات. نملة أداة استطلاع فقط: بتكتشف وبتوثّق ولا تستغل أي ثغرة، وهذا مقصود.
